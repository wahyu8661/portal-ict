A. Kelompok Pertama

Perangkat Lunak (Software)

Alur Sistem & Aplikasi

1. Sistem Analis

Menganalisa sistem yang akan diimplementasikan, kelebihan & kekurangannya, studi kelayakan, hingga desain sistem.

2. Programmer

Mengimplementasikan rancangan sistem analis menjadi program nyata (aplikasi maupun sistem operasi).

Alur Aplikasi Web

3. Web Designer

Melakukan perencanaan, studi kelayakan, analisis, dan desain tampilan/struktur proyek aplikasi berbasis web.

4. Web Programmer

Mengimplementasikan rancangan web designer menjadi program berbasis web yang fungsional.

B. Kelompok Kedua

Perangkat Keras (Hardware)

Technical Engineer (Teknisi)

Berkecimpung dalam bidang teknik pemeliharaan maupun perbaikan perangkat keras komputer.

Networking Engineer

Menangani bidang teknis jaringan komputer mulai dari maintenance hingga troubleshooting.

C. Kelompok Ketiga

Operasional Sistem Informasi

MIS Director

Wewenang Tertinggi

Memiliki wewenang tertinggi terhadap sistem informasi; memanajemen hardware, software, dan SDM secara keseluruhan.

System Administrator

Melakukan administrasi & pemeliharaan sistem, serta mengatur hak akses operasional sistem.

EDP Operator

Mengoperasikan program-program yang berhubungan dengan Electronic Data Processing (EDP) di organisasi.
